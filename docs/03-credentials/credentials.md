# 凭据完整 SOP

## 目标

以不暴露秘密为前提，完成凭据的创建、绑定、验证、轮换和删除，并能证明流程没有继续引用已撤销凭据。

## 适用角色

流程搭建者负责提出最小权限需求；管理员负责创建、轮换、撤销和审计。普通学员只使用讲师预置的合成凭据。

## 适用版本与功能状态

适用于 Flowise `3.1.3`、提交 `6a5bb28b…` 的 `production-enabled` 凭据模块。OAuth 字段和共享权限以目标部署实际开关为准。

## 前置条件与风险

- 已获得培训环境管理员权限和合成 Provider／服务账号。
- 明确凭据所有者、用途、环境、最小权限、失效时间和预计费用。
- 凭据可能开启外部调用、产生费用或写入；禁止使用生产密钥和真实数据。

## 初始状态

从凭据列表开始，确认没有同名测试对象、浏览器录屏已关闭、开发者工具不会保留请求正文，费用账本仍有余额。

## 操作步骤

1. 按“环境—服务—用途”命名，避免在名称中放入账号、Key 片段或客户信息。
2. 选择准确的凭据类型，只填写必需字段；秘密通过受控输入进入平台秘密存储。
3. 保存后回到列表，确认敏感字段被遮罩，页面和 URL 没有明文。
4. 在最小实验流程绑定凭据，只发送合成输入并运行一次。
5. 在执行记录核对成功、耗时、费用和外部目标；确认输入输出、日志、导出物不回显秘密。
6. 轮换时先创建新凭据并验证，再切换引用、观察、撤销旧凭据。
7. 删除前列出关联流程；删除后重新打开这些流程，确认不会静默回退到其他凭据。

## 逐步检查点

- 创建后：类型正确、字段已遮罩、名称无敏感信息。
- 绑定后：仅目标流程引用，未改变其他节点。
- 执行后：Provider、模型、token、费用和错误均进入实验账本，秘密扫描为零命中。
- 轮换后：旧凭据调用失败或已撤销，新凭据主链成功，未产生双写。

## 业务权限与凭据权限必须同时满足

能查看某个业务对象，不代表可以代该对象解密 Provider 凭据。目标候选中，旧版 OpenAI Assistant／Vector Store 的 Provider-backed 读取与非破坏性更新同时要求对应的 `assistants:view`／`assistants:update` 和 `credentials:view`。测试角色应分别验证“只有业务权限”“只有凭据权限”“两者都有”三种组合；前两种必须固定拒绝，不能用前端隐藏代替服务端授权。

Provider 返回的分页若缺少数组 `data`、含无效或重复 ID、无法继续翻页或超过有界页数／条数，整次读取应失败。界面显示“空列表”不能作为 Provider 确认无文件的证据，先检查错误和请求回执。

## 成功结果

凭据只存在于培训环境秘密存储；目标流程能用合成数据完成一次受控调用；旧凭据已撤销且关联引用已清零。

## 常见错误与诊断

- “无法解密”：先核对加密密钥和数据卷连续性，不要反复保存覆盖原密文。
- “认证失败”：区分字段错误、账号权限、目标环境、时钟和 Provider 限流。
- 节点找不到凭据：核对工作空间、凭据类型和当前角色，不以列表可见推断节点可读取。
- 删除后流程仍成功：检查缓存、环境变量或另一个同名凭据，禁止把偶然成功当作撤销证明。

## 回退与清理

失败时停止外部调用，恢复上一已验证的引用；撤销本次新建凭据，删除合成流程和调用对象，并复核实验 ledger 与残留清单。

## 安全提示

不要把 Token 放入变量、节点说明、URL、导出 JSON、截图、终端历史或 Git。若疑似泄露，立即撤销、查调用范围、轮换依赖并清理历史制品。

## 练习任务

用讲师提供的合成工单 API 凭据完成“创建—绑定—一次查询—轮换—撤销”，并提交不含秘密的检查点记录。

## 验收清单

- [ ] 字段遮罩、秘密扫描和最小权限通过。
- [ ] 合成调用成功，Provider 与费用已记账。
- [ ] 轮换前后引用与运行结果可追溯。
- [ ] 旧凭据撤销，测试对象与残留清零。
