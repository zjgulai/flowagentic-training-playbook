# FlowAgentic 培训与操作 Playbook

这是一份面向真实操作的中文培训手册。它解释怎样使用 FlowAgentic，也解释操作为什么有效、可能影响什么，以及失败时怎样安全地回到可控状态。

## 四条学习路径

### 新手使用者

从[30 分钟快速体验](quickstart.md)开始，然后依次阅读登录、Chatflow、执行记录和故障排查。目标是能够登录、运行既有流程、判断结果是否可信，并知道何时停止操作和求助。

### 流程搭建者

重点学习凭据与变量、Chatflow、Agentflow V2、Tools/MCP、文档库与 RAG。目标是独立搭建一个可测试、可诊断、可回退的流程，而不把密钥或真实数据写进流程。

### 二次开发者

先掌握系统数据流，再进入开发者专区。目标是沿着“前端页面 → 路由 → 控制器 → 服务 → 数据库或节点池”定位行为，添加节点或凭据，并用分层测试保护兼容性。

### 管理员／运维人员

重点学习管理员单账号、权限边界、密钥连续性、日志原则、发布验收和公开 Runbook 边界。目标是维护系统可用性，同时避免把内部拓扑、真实恢复命令和凭据发布到公开站。

## 功能状态图例

- `production-enabled`：在本 Playbook 的目标产品主线中按正式能力编写完整 SOP；当前运行环境是否已启用仍以部署与验收回执为准。
- `feature-gated`：上游或代码中存在，但当前部署受功能开关、许可证或权限约束。
- `deprecated`：已弃用，仅用于迁移和兼容说明。
- `experimental`：实验能力，不承诺生产稳定性。
- `upstream-only`：上游存在，但本部署未启用或未完成本地验证。

## 安全与费用底线

1. 培训只使用虚构企业、员工、知识库和工单数据。
2. 凭据只进入培训环境的秘密存储，不写入文档、截图、Git 或聊天记录。
3. Provider 实验总费用上限为人民币 300 元；DeepSeek 与 Kimi 的账户子限额合计不得超过 300 元。只有子限额、关闭自动充值、本地一次性预算代理和受信执行签名四项均有回执时才开放调用，任一控制异常立即停止。
4. 任何删除、公开发布、外部 API 写入或恢复操作都先确认对象、影响范围和回退路径。
5. 公开 Playbook 只保留安全原则；真实拓扑、备份恢复命令和回执属于私有 Runbook。

## 阅读每个 SOP 的方法

每页顶部都标出适用角色、版本、功能状态、权限、费用、可能副作用、证据和截图。执行时按“前置检查 → 编号步骤 → 每步检查点 → 成功标准 → 回退与清理”的顺序阅读，不要只照着按钮点击。
