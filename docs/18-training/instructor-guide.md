# 讲师手册与演示脚本

## 授课边界

讲师负责让学员在隔离环境完成可复现任务，而不是代替学员修复生产。生产站只用于只读核对页面与术语；所有创建、Provider 调用、Webhook、Schedule、Tool 写入和清理均在同版本培训环境进行。任何真实账号、客户数据、内部域名、Token 或生产资源 ID 出现在投屏中，都必须立即停止演示并按泄露响应流程处理。

## 开课前门禁

| 时间 | 讲师动作 | 必须留下的证据 | 不通过时 |
| --- | --- | --- | --- |
| T-7 天 | 冻结课程版本、镜像、迁移和功能开关 | 版本 SHA、差异矩阵、功能状态表 | 延期截图与实操 |
| T-2 天 | 重建合成企业、知识库与工单 fixture | fixture 哈希、对象 ledger | 重建，不沿用旧班对象 |
| T-1 天 | 验证登录、十个主模块、13 节点和失败 fixture | 路由清单、截图 manifest、浏览器结果 | 将失败能力从课程中移除并标注 |
| T-1 天 | 校验 DeepSeek/Kimi 凭据与预算 | Provider allow-list、¥300 预算状态 | 全部 Provider 实验改为讲解模式 |
| T-30 分钟 | 清空演示对象、会话和临时密钥 | 残留检查为零 | 不开课，先执行清理 |
| T-10 分钟 | 投屏隐私检查与浏览器缩放 | 1440×1000、100%、zh-CN、浅色主题 | 修正后重新走登录页 |

开课口令不是“环境能打开”，而是“版本、数据、权限、费用、副作用和清理责任均可说明”。

## 30 分钟管理入口脚本

| 分钟 | 演示动作 | 讲师必须说清楚 | 学员检查点 |
| ---: | --- | --- | --- |
| 0–3 | 展示版本、功能状态和培训边界 | 可见不等于启用，生产只读 | 能指出版本 SHA 与状态图例 |
| 3–6 | 管理员登录 | 单管理员、注册关闭、失败限流 | 登录后地址离开 `/signin` |
| 6–10 | 依次定位十个主模块 | 对象之间的依赖关系 | 能说出 Chatflow、Credential、Execution 的关系 |
| 10–15 | 打开已准备的 FAQ Chatflow | 画布保存不等于运行成功 | 能找到模型、输入与输出节点 |
| 15–20 | 用合成问题运行一次 | Provider、token、延迟和费用 | 能指出本次执行是否真实调用 Provider |
| 20–24 | 打开执行记录 | 从症状到首个异常节点 | 能找到输入、输出、错误与耗时 |
| 24–27 | 演示一个安全失败 | 失败分支、回退和清理比“再点一次”重要 | 能说明为何不能盲重试 |
| 27–30 | 退出并访问受保护路由 | Cookie、会话和路由保护是不同证据 | 受保护路由返回登录页 |

若第 15–20 分钟的 Provider 门禁未通过，改用预录的合成执行回执讲解，并明确标注“未执行实时调用”。

## 第一天讲师节拍

### 模块一：认知、登录和证据边界

先让学员画出 Browser → API → Service → Node/Provider → Database 的数据流，再进入 UI。提问“页面出现成功提示能证明什么”，要求答案只覆盖 UI 反馈，不能推断数据库、外部系统或生产发布。

### 模块二：凭据、变量和 API 密钥

讲师演示遮罩后的合成 Credential、静态变量、Runtime 变量和请求级覆盖。故障注入为“变量名正确但作用域错误”；学员必须从执行输入定位最终取值，而不是把 Key 写进节点文本。结束时轮换或删除课程密钥，并检查截图与日志无明文。

### 模块三：最小 Chatflow

按“空白画布 → 节点 → 连接 → 参数 → 验证 → 保存 → 重开 → 测试 → 执行记录”顺序演示。故障注入只选择一个：未绑定 Credential、输入变量拼写错误或模型超时。每次故障先保存证据，再做最小修复。

### 模块四：文档库与 RAG

使用固定中文手册完成 Loader、Splitter、Chunk Preview、Metadata、Embedding、Vector Store、Process/Upsert 和 Retrieval Playground。至少比较一次有答案与无答案问题；不允许只用最终聊天回答判断检索质量。

## 第二天讲师节拍

### 模块五：Agentflow V2

从 Start Schema 和 Flow State 表开始，再加入 Condition、LLM、Tool、HITL、Iteration 与 Execute Flow。每加入一种控制结构就运行一个最小输入。讲师必须展示循环上限、确定性兜底分支和写入 Tool 的幂等键。

### 模块六：Tools 与 MCP

先做只读工单查询，再做需要人工批准的模拟更新。解释 Custom Tool 参数 Schema、HTTP/MCP 传输、授权与工具发现。出现超时、SSRF 风险或工具发现异常时，停止在诊断层，不把地址改成真实内网服务。

### 模块七：执行诊断

给每组不同故障 fixture：401、429、RAG 空召回、维度不匹配、Tool 409 幂等冲突、HITL 无法恢复。学员使用“时间线 → 首个异常节点 → 输入 → 输出 → 外部回执 → 修复 → 复跑”模板提交报告。

### 模块八：综合考核与清理

综合题要求构建工单条件分流：普通问题直接回复，高风险工单进入 HITL，批准后调用幂等更新。评分完成后立即禁用 Schedule/Webhook、撤销临时密钥并清理对象；未清理不得宣布结业。

## 开发者扩展课脚本（4 小时）

1. 45 分钟：六包 monorepo、UI → Route → Controller → Service → Database/NodesPool 请求追踪。
2. 60 分钟：从节点 metadata、Credential 声明到 UI 参数表，完成一个不调用外网的合成节点阅读练习。
3. 45 分钟：Prediction、SSE、错误与中断路径；用固定 fixture 验证 `metadata/token/end/error`。
4. 45 分钟：单元、合同、集成、浏览器和发布门禁的职责分层。
5. 30 分钟：中文文案、权限、租户和 feature-gated 边界审查。
6. 15 分钟：上游差异矩阵与升级决策。

开发者练习不得修改生产源码或推送现有产品仓库；所有补丁在独立练习分支或临时副本完成。

## 管理员与运维课脚本（3 小时）

1. 30 分钟：管理员单账号、登录限流、会话撤销和注册关闭。
2. 45 分钟：加密密钥、数据卷、Credential 连续性与备份恢复证据。
3. 30 分钟：日志、审计、费用和外部调用边界。
4. 45 分钟：候选版本、只读预检、发布、健康检查、回滚判定和残留检查。
5. 30 分钟：公开 Playbook 与私有 Runbook 的分界。

真实拓扑、远程命令和备份位置只能引用私有 Runbook 编号，不能投屏或写入公开课程。

## 故障注入与停止规则

| 故障 | 可演示范围 | 立即停止条件 | 恢复完成条件 |
| --- | --- | --- | --- |
| Provider 429 | 合成请求、单次重试 | 预算、重试上限或凭据不明 | 无新调用，ledger 可解释 |
| Tool 409 | 同一幂等键重复请求 | 外部对象状态不确定 | 查询回执确认仅一次写入 |
| RAG 空召回 | 合成文档库 | 尝试导入真实文档 | Loader/Upsert/检索逐层恢复 |
| HITL 停止 | 培训执行记录 | 原执行、版本或审批者不明 | 从原执行 Proceed/Reject 并留回执 |
| Webhook 失败 | 本地模拟端点 | 地址指向内网或生产 | 注册、认证、请求和响应均匹配 |

出现秘密回显、真实数据、未知外部写入、预算无法计算、对象归属不明或清理失败时，全班停止继续点击，由讲师执行隔离和证据保全。

## 讲师收尾回执

- [ ] 所有组提交对象 ID ledger、费用 ledger 和诊断报告。
- [ ] 临时 Credential、API Key、变量、Schedule、Webhook 和 MCP Token 已撤销。
- [ ] Chatflow、Agentflow、Assistant、Tool、文档库、向量集合和模拟工单残留为零。
- [ ] Provider 费用不超过 ¥300，未结算 reservation 有明确处置。
- [ ] 失败与改进已回写 SOP，不在现场静默修改培训基线。
- [ ] 截图、录像和导出文件通过公开安全扫描后才可保留。
