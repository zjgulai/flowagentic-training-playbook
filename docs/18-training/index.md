# 培训与考核

## 课程总览

### 30 分钟管理入口和首个流程

适合管理者和首次接触者：环境识别、十个主模块、运行合成问题、查看执行记录、安全退出。

### 第一天：基础与 Chatflow

| 时段 | 内容 | 产出 |
| --- | --- | --- |
| 09:00–10:00 | 系统认知、登录、导航 | 能解释核心对象和证据边界 |
| 10:15–11:30 | 凭据、变量、API 密钥 | 完成秘密治理练习 |
| 13:30–15:30 | 最小 Chatflow | 可保存、测试和诊断的 FAQ 流程 |
| 15:45–17:00 | 文档库与 RAG | 合成知识库与检索测试 |
| 17:00–17:30 | 清理与复盘 | ledger 无残留 |

### 第二天：Agentflow 与诊断

| 时段 | 内容 | 产出 |
| --- | --- | --- |
| 09:00–11:00 | Agentflow V2 与 13 节点 | 条件分流流程 |
| 11:00–12:00 | Tools 与 MCP | 只读工单查询 |
| 13:30–15:00 | HITL 与模拟工单更新 | 可审批、可拒绝、可恢复 |
| 15:15–16:15 | 执行诊断与成本 | 完成故障定位报告 |
| 16:15–17:00 | 综合考核与清理 | 通过验收并无残留 |

### 4 小时开发者扩展课

monorepo 架构、请求追踪、添加节点与 Credential、API／Streaming、测试分层、中文和权限规范、上游差异审计。

### 3 小时管理员／运维课

单账号安全、功能开关、加密与数据连续性、日志原则、备份恢复证据、发布回滚和公开／私有文档边界。

## 讲师演示规则

- 每次演示先说目标、权限、费用、副作用和成功标准。
- 只使用讲师基线对象或明确登记的新对象。
- 遇到失败先展示诊断，不临场输入真实 Key 或改生产。
- 正式截图仅来自同版本隔离环境；投屏前关闭敏感弹窗。
- 课程结束按 ledger 逐项清理并做残留检查。

## 盲走验收

四类角色分别在不看讲师操作的情况下完成指定任务。观察员只记录阻塞，不实时提示。阻塞要回写到 SOP、术语、截图或导航，并由不同评审者复测。

## 结业条件

- 能说明页面可见、运行成功、业务回执和生产发布证据的区别。
- 能完成对应角色的主链任务和至少一个失败恢复任务。
- 无秘密、真实数据、未知外部写入或未清理对象。
- 测验达到 80 分；高风险题必须全部正确。
