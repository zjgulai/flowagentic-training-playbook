# 研究与验证方法

这份 Playbook 不把“官方文档写了”“源码里有这个类”或“某位开发者遇到过”直接等同于目标系统事实。所有对外结论先进入来源库，再进入 Claim—Evidence 矩阵，最后按目标提交和隔离培训环境完成复现。当前研究基线为 Flowise `3.1.3` 与提交 `96f6ae464f7f4757883a5ba6bec26ca951b4da4d`；正式截图和发布版本必须在这一精确提交的同版本隔离培训环境完成复现后绑定。

## 八阶段流程

### 1. SCOPE：界定问题

研究覆盖四类读者：新手、流程搭建者、二次开发者和管理员。公共范围包括十个主模块、13 个 Agentflow V2 核心节点、固定提交中的节点参数目录、API/Embed/MCP/RAG 使用方法、安全边界、失败模式和优化建议。真实基础设施拓扑、真实账号、备份恢复命令、部署密钥和生产回执明确排除在公开站之外。

### 2. PLAN：建立证据层级

证据分为四层。第一层是目标提交的源码、测试、构建或浏览器证据；第二层是 Flowise 官方文档、API 文档和包说明；第三层是 Release、PR、Issue 中的维护者记录；第四层是其他开发者的一手案例。核心功能结论至少需要“目标事实＋官方语义＋培训环境复现”，优化建议还要有两个独立案例或一个可重复的控制实验。

### 3. RETRIEVE：只收集可追溯来源

每项来源都记录唯一 ID、标题、URL 或固定提交锚点、发布者、作者、适用版本、发布日期、访问日期、可信度、公开安全状态和限制说明。滚动官方文档若晚于目标版本，会被标记为版本风险；未给出版本的问题报告只用于生成测试假设。

### 4. TRIANGULATE：三角验证

对“本系统有此功能”的验证顺序是：

1. 固定 SHA 中是否存在对应路由、权限、服务或节点；
2. 官方资料如何定义该功能及限制；
3. 同镜像隔离环境能否完成成功、失败、权限不足和恢复路径。

缺少第三步时，结论状态保持“等待培训环境复现”。开发者 Issue 无论描述多具体，都不会单独升级为目标系统缺陷。

### 5. OUTLINE：让证据修正目录

研究发现两个必须独立呈现的边界。第一，目标 UI 的十个主模块与评估、RBAC、SSO 等 feature gate 不是同一个可用性层级。第二，Agentflow 可嵌入包列出 13 个节点，但包本身仍声明为 Dev。站点目录因此把“生产主链”“受限能力”“SDK/实验能力”分栏，而不是按上游产品宣传页平铺。

### 6. SYNTHESIZE：形成可执行建议

综合结论必须回答五个问题：适用谁、适用哪个版本、需要什么权限、会产生什么费用或副作用、如何验证成功。比如“启用 Streaming”不是建议；“验证 metadata、token、end、错误、中断和无内容事件，并检查浏览器网络流是否包含不应暴露的数据”才是可执行建议。

### 7. CRITIQUE：对抗性复核

每批研究由三种视角复核：

- 日常使用者检查步骤是否真的可走通；
- 对抗性评审检查单一来源、版本漂移、秘密泄露和过度结论；
- 实施工程师检查建议是否有 fixture、检查点、清理动作和失败出口。

当前已固定并复核中文源码候选 SHA，同版本隔离培训环境也已完成基础运行验收；该候选的生产部署／PC 验收回执、功能专项复现和 Provider 安全凭据仍未提供。因此最终截图、真实 DeepSeek/Kimi 调用和发布证明均保持关闭，不使用模拟成功替代。

### 8. PACKAGE：发布可审计产物

研究产物由以下文件组成：

- `research/sources.yml`：全量来源和可信度；
- `research/claims.yml`：Claim—Evidence 矩阵；
- `research/report.md`：原创中文综合报告；
- 本页：方法、边界和质量门禁；
- [研究来源](research-sources.md)：面向读者的来源导航；
- [版本差异](version-diff.md)：目标版本与上游差异。

## 可信度评分

可信度是证据选择的排序指标，不是“正确率”。固定提交的直接源码和测试通常为 94–98；官方一手资料为 89–94，但滚动页面会因版本漂移降分；合并 PR 和 Release 为 88–94；有复现步骤的一手 Issue 为 65–72。任何低于 75 的单项来源都不得独立支撑核心功能结论。

## 发布门禁

正式发布前，所有核心 Claim 必须达到三角验证状态；所有经验建议必须能说明证据、适用条件和不适用情况；每个截图必须绑定新 SHA、角色、状态和脱敏结果。缺少任何一项时，站点可以作为内部研究预览构建，但不能更新 `latest` 或对外宣称完成。
