# 登录、导航与账户

## 目标

安全登录管理员账号，识别当前环境和权限，完成导航、主题切换和退出；对失败、限流、无权限与账号恢复保持明确边界。

## 登录 SOP

### 前置检查

- 确认地址栏是目标环境的 HTTPS 域名。
- 确认培训或生产环境标签，不凭页面外观猜测环境。
- 管理员凭据来自受控秘密渠道，不从文档、工单或聊天复制。
- 共享屏幕前关闭密码管理器弹窗和浏览器自动填充建议。

### 操作

1. 打开登录页，确认没有“公开注册”入口。
2. 输入管理员邮箱；输入密码时保持遮罩，需要核对时短暂使用“显示密码”。
3. 只提交一次，等待服务端响应。
4. 登录后先核对主导航和当前工作空间，再开始业务操作。

检查点：成功进入主页面；地址仍是预期域名；页面没有暴露密码；浏览器控制台无与登录主链相关的错误。

## 失败处理

| 状态 | 含义 | 动作 |
| --- | --- | --- |
| 凭据错误 | 邮箱或密码不匹配 | 检查大小写和输入法；不要连续猜测 |
| 401 | 会话无效或身份未认证 | 退出旧会话，重新登录一次 |
| 403 | 已登录但没有权限 | 记录目标页面和角色，交由管理员处理 |
| 429 | 触发限流 | 停止尝试，等待限流窗口；不要换设备绕过 |
| 5xx | 服务端异常 | 保存时间和请求标识，转入故障排查 |

连续失败不是继续试密码的理由。达到组织规定的失败次数后应停止，防止锁定或掩盖攻击。

## 忘记密码与恢复边界

如果当前部署没有经过验证的自助重置链路，不应向学员承诺“忘记密码”按钮一定能发信。管理员恢复需由受控身份核验和私有 Runbook 完成。公开 Playbook 只说明原则，不发布数据库改写、内部命令或真实接收地址。

## 主导航与账户操作

- 使用侧边栏进入十个主模块；先观察当前筛选和工作空间。
- 主题切换只改变显示，不改变业务对象；培训截图以浅色主题为基线。
- 账户设置涉及个人资料或安全选项时，先确认是否会写入。
- 退出后用浏览器后退键验证受保护页面不能继续访问。

## 验收与清理

- 能说明 401 与 403 的区别。
- 能在不暴露密码的情况下完成登录。
- 退出后会话失效，受保护页面要求重新认证。
- 不在共享设备保存管理员密码。
