# 模板市场

## 使用原则

Community 模板和 My Templates 都是加速器，不是安全或可用性背书。模板中的节点、模型、凭据占位符、文档库和环境依赖必须逐项复核。

## 使用模板 SOP

1. 按业务目标搜索和过滤，而不是只看名称。
2. 预览节点、外部依赖、版本、说明和潜在副作用。
3. 选择 Use Template 后立即重命名，写入实验对象 ledger。
4. 替换所有凭据、变量、文档库、URL 和模型配置。
5. 删除不理解或不需要的节点，不保留“以后可能用”的外部调用。
6. 运行画布验证、秘密扫描和合成数据测试。
7. 查看执行记录，确认没有隐藏调用和意外费用。

## 自建模板

保存或分享前移除凭据引用、内部 URL、真实数据和环境专属资源 ID。写明适用版本、依赖、输入输出、费用和验证日期。删除共享模板前确认是否存在学员或流程依赖。

## 版本漂移

模板作者更新、节点升级或 Provider 参数变化都可能造成漂移。每次导入都记录模板来源和时间，并在目标提交重新验证；“曾经运行成功”不能替代当前证据。

## 目标

安全地预览、导入、适配、验证和清理模板，不继承来源环境的凭据、数据和可用性假设。

## 适用角色

新手负责搜索预览，搭建者负责节点适配，管理员负责分享、删除和外部依赖审查。

## 适用版本与功能状态

模板市场在基线为 `production-enabled`；模板内容自身可能来自不同版本，必须单独记录来源和验证日期。

## 前置条件与风险

需要隔离工作空间、对象 ledger、受控凭据和合成数据。导入会创建流程，隐藏节点可能调用 Provider、内网或外部写入。

## 初始状态

从 Community／My Templates 列表开始，清空筛选，记录目标模板来源、版本、作者和当前时间，不直接点击使用。

## 操作步骤

搜索过滤 → 预览节点和依赖 → Use Template → 立即重命名 → 替换凭据／变量／文档库／URL → 删除未知节点 → 验证 → 合成运行 → 执行检查。

## 逐步检查点

每个外部依赖有所有者；无真实资源 ID；导出物通过秘密扫描；执行只命中批准目标；费用与写入均可追溯。

## 成功结果

新流程可在目标版本保存重开并完成合成运行，所有来源环境依赖已被替换，模板漂移记录完整。

## 常见错误与诊断

节点缺失检查版本和组件包；凭据错误重新绑定而非复制原值；文档库为空检查 Upsert；隐性费用从执行树逐节点定位。

## 回退与清理

删除导入产生的新流程和外部对象，撤销临时凭据；不修改原模板。分享失败时撤回公开状态并清查缓存链接。

## 安全提示

模板不是代码审查或安全背书。自定义函数、HTTP、Tool、MCP、外部 URL 和写入节点必须视为不可信输入。

## 练习任务

导入一个 FAQ 模板，替换全部环境依赖，删除一个无关外调节点，运行正常与失败 fixture 后完整清理。

## 验收清单

- [ ] 来源、版本、依赖和漂移已记录。
- [ ] 凭据、URL、变量、文档库全部替换。
- [ ] 执行、费用、秘密和残留检查通过。
