    30 分钟快速体验¶

    目标¶

    在隔离培训环境中完成一次“登录 → 打开既有流程 → 运行合成问题 → 查看执行记录 → 安全退出”的闭环。当前页不要求创建 Provider 凭据，也不要求操作生产环境。

    前置条件¶

    • G1 全中文版本门禁已通过，培训环境与目标发布 SHA 一致。
    • 讲师已经创建只包含合成数据的演示流程。
    • 管理员账号通过安全渠道提供；密码不出现在教材或投屏画面。
    • 若流程会调用 DeepSeek 或 Kimi，费用 ledger 已启用且剩余额度大于本次预算。

    如果任一条件不满足，改用页面导览和执行记录样例讲解，不进行真实调用。

    操作步骤¶

    1. 登录并确认环境¶

    打开培训环境登录页，输入管理员邮箱和密码。登录后先检查页面标题、版本标识和地址栏域名，确认不是生产环境。

    检查点：

    • 页面进入主导航，而不是停留在登录页或显示 401/403。
    • 当前环境标签明确为培训环境。
    • 浏览器没有保存或自动填充其他环境的凭据。

    2. 认识主导航¶

    依次定位对话流程、Agentflow、执行记录、自定义助手、模板市场、工具、凭据、变量、API 密钥和文档库。此步骤只观察，不创建或删除对象。

    检查点：十个主模块均可定位；不可见模块先记录角色和功能开关，不自行修改权限。

    3. 运行既有演示流程¶

    打开讲师指定的“虚构企业 FAQ”流程，进入聊天测试面板，输入：

    星桥科技的工单升级时限是多少？请给出答案来源；不知道时明确说不知道。

    等待结果完成，不要连续重复提交。若出现超时或 429，停止重试并进入故障排查。

    检查点：

    • 回答与合成知识库一致。
    • 页面显示来源时，来源只指向合成文档。
    • 若启用 Provider，ledger 新增一条含模型、token、延迟和估算费用的记录。

    4. 查看执行记录¶

    打开执行记录，按流程和时间找到刚才的运行。查看执行树、每个节点的输入输出、耗时、错误和 token／费用字段。

    检查点：Session、开始时间与刚才的操作一致；任何敏感字段应被遮罩。

    5. 退出并清理¶

    返回聊天测试面板，不再发送请求。关闭测试会话，通过个人菜单退出。讲师按实验 ledger 清理本次产生的会话和执行对象。

    成功标准¶

    • 学员能说出十个主模块各自解决的问题。
    • 能从一次回答追踪到对应执行记录。
    • 能区分“页面可见”“操作成功”和“生产可用”三种证据。
    • 没有真实数据、凭据或内部资源标识进入输入、截图或仓库。

    常见失败与回退¶

    症状 先检查 安全动作
    登录后又回到登录页 Cookie、系统时间、账号状态 停止重复尝试，交给管理员检查
    节点或流程列表为空 工作空间、权限、筛选条件 清除筛选；不要创建重复对象
    Provider 429 限流与费用 ledger 停止自动重试，按退避策略稍后再试
    找不到执行记录 时间范围、流程和 Session 扩大只读筛选，不重新触发调用
