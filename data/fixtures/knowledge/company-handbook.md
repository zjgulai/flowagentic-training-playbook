# 星桥科技（虚构）知识库

本文档仅用于 FlowAgentic 培训。所有企业、人物、产品、工单和规则均为合成数据。

## 服务时间

技术支持服务时间为工作日 09:00–18:00。高优先级培训工单由值班支持工程师在两个模拟小时内响应。

## 产品线

- 星图：企业知识检索产品。
- 流光：工单分类与路由产品。
- 云桥：只读 API 与 MCP 集成演示产品。

## 工单优先级

高优先级表示核心培训链路不可用；中优先级表示功能受限但存在替代路径；低优先级表示咨询或体验优化。

## 数据安全

培训环境只允许使用合成数据。不得上传真实个人信息、生产日志、内部域名、访问令牌或客户材料。
